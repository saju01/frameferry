# Community conduct

FrameFerry welcomes contributors of all backgrounds and experience levels.

Be respectful, assume good intent, and critique ideas rather than people. Helpful
bug reports, careful review and honest disagreement are welcome. Harassment,
discrimination, threats, doxxing, sexualized content directed at participants,
spam and sharing others' private data are not acceptable.

Saju (@saju01) moderates this repository and may edit/remove inappropriate
content or limit participation. Moderation should be proportionate and protect
participants' privacy. This applies in issues, PRs, reviews and other project
spaces; it does not create a right to harass people elsewhere.

Use GitHub's **Report content** / **Report abuse** controls for sensitive conduct
reports; do not post private evidence in a public issue. For a non-sensitive
moderation question, ask the maintainer in a project discussion or issue without
identifying private parties. Security vulnerabilities use the separate private
route in SECURITY.md.
